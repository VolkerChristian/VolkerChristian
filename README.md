# Volker Christian

I'm a professor of Multimedia Programming at the University of Applied Sciences Upper Austria, Campus Hagenberg, with a background in theoretical physics.

My work brings together software development and teaching: C++ networking, connected devices, and tools for working with coding agents.

## Open source

I maintain the [SNode.C ecosystem](https://github.com/SNodeC#banner), centred on the SNode.C C++ networking framework.

| Project | Explore |
| --- | --- |
| [SNode.C](https://github.com/SNodeC/snode.c#banner) | C++ networking framework |
| [MQTTSuite](https://github.com/SNodeC/mqttsuite#banner) | MQTT applications and integrations |
| [AISuite](https://github.com/SNodeC/AISuite#banner) | Application integration with coding agents |
| [CodexUI](https://github.com/SNodeC/CodexUI#banner) | A workspace for working with Codex |

See the [organization profile](https://github.com/SNodeC#banner) for examples, documentation, and the wider project directory.

## Teaching and student projects

Alongside my own development work, I teach programming and supervise student projects at Campus Hagenberg.

[Lokato](https://github.com/lokato-at/lokato-main) is one of the projects I co-supervise: a student-built room-occupancy system for after-school childcare, combining RFID hardware with a web application.
